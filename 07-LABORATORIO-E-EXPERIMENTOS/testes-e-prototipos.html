O QUE É O LABORATÓRIO

O Laboratório é o espaço de criação e teste. Aqui nada é proibido de tentar. Aqui erramos, corrigimos, aprendemos e fazemos melhor. Antes de qualquer coisa ir para o mundo real — ela vem primeiro aqui, no Laboratório.

📐 AS REGRAS DO LABORATÓRIO

✅ Errar é permitido. Aqui se testa. Aqui se ajusta. Aqui se melhora.

✅ Uma coisa de cada vez. Testa → avalia → corrige → aprova.

✅ Só passa pra frente quando estiver pronto. O que não está pronto fica aqui até estar.

✅ Todo teste fica registrado. O que funcionou, o que não funcionou, o que foi mudado.

✅ Do Laboratório → para o Mundo. Só depois de testado e aprovado, vai pra Biblioteca e pra Raiz.

🔄 O CAMINHO DA CRIAÇÃO

Ideia → Laboratório → Teste → Correção → Aprovação → Biblioteca → Raiz → Pronto para sempre.
