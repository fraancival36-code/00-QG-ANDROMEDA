📐 COMO NAVEGAR PELO SISTEMA

Passo 1 — Sempre começa pela Raiz

A página principal é o INDEX.HTML. Tudo começa ali. Cada botão leva a uma pasta. Cada pasta tem suas páginas.

Passo 2 — Sempre tem caminho de volta

Toda página tem botão: VOLTAR À RAIZ. Não importa onde esteja, sempre volta. Nenhuma página fica perdida.

Passo 3 — Como escrever os caminhos

Para ir da Raiz para uma pasta: escreve o nome da pasta, barra, nome do arquivo.

01-CONSTITUICAO/constituicao.html

Para voltar de uma pasta para a Raiz: dois pontos, barra, index.

../index.html

📂 COMO CRIAR UMA PÁGINA NOVA

✅ Primeiro: Verifica se já não existe no Mapa.

✅ Segundo: Cria a pasta com número e nome — ex: 17-NOVA-PASTA.

✅ Terceiro: Cria o arquivo dentro da pasta com nome claro.

✅ Quarto: Coloca o botão de VOLTAR À RAIZ.

✅ Quinto: Coloca o botão de acesso na página principal.

🛡️ REGRAS DE OURO QUE NUNCA SE ESQUECE

🔹 Não se cria sem caminho. Se não tem botão de entrada e botão de volta, não existe página.

🔹 Não se muda o nome sem atualizar tudo. Se muda o nome da pasta, atualiza todos os botões que ligam a ela.

🔹 Não se apaga sem registrar. Antes de excluir qualquer coisa, guarda cópia no Arquivo.

🔹 Um de cada vez. Termina uma página, depois cria a próxima. Não mistura. Não confunde.

🔄 O FLUXO PERFEITO

Ideia → Verifica o Mapa → Cria Pasta → Cria Página → Coloca Botão de Voltar → Coloca Botão na Raiz → Testa Ida e Volta → Pronto.

"Quem segue o caminho, nunca se perde. Quem segue as regras, nunca se confunde."
